# 恢复分支限制（待独立验证）

- 2026-11-12：A2A 入站幂等键由旧的主体、消息、正文和参数组合改为可信调用方标识及消息 ID。**旧账本中的键不会自动迁移**。只读聚合本机历史账本 2,122 行、84 条受理记录：未见 messageId/message_id；旧主体还可能由请求自行声明，无法可靠反推。升级后重试可能创建新任务。生产迁移前须冻结未证实的旧重试；只有可信且完整的原始请求能按旧公式唯一命中旧任务并校验完整语义时，才可建立持久、唯一、原子的别名映射。无法证明时须人工对账；不得以正文相似度猜测。仅修改键公式不构成安全迁移。
- 调用方 `created_by` 必须由可信认证边界提供，不能直接取自远程请求；本目录尚未提供跨域身份认证。为防止未经迁移的旧重试被再次执行，`inbound_bridge.submit` 当前在连接 NATS 前一律拒绝；这条门禁是临时隔离，不是旧键迁移实现，也不拦截其他可直接访问 Hub 的客户端。
- 入站外部动作（`external`）当前默认拒绝，因为尚无可信审批校验与中枢格式转换；非空审批对象不构成授权。
- HubSingleton 是独立实验守卫，未接入 Hub 派发，且不提供跨机共识；不得声称消除多 Hub 双派发。
- 本机 NATS 实验只验证受理、查询、重试和冲突拒绝，未验证真实席位派发、执行及结果返回，不等于 A2A 标准互操作闭环。
- 出站 EventBridge 默认禁用：独立审查复现跨批次 result_ready 与指针分离导致产物丢失、终态重复、同批多裁定倒序，以及半行记录被跳过。测试专用开关仅供复现旧行为，不能用于生产；修复并完成独立故障注入前不得启用。HTTP SSE 原路径有类似半行和产物静默丢失风险，现返回 503，直到重建并独立验证；普通只读任务查询不受此门禁影响。
